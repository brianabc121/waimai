## 适用范围与评审口径

本稿承接最新中文版效果图，以及随后新增的自定义工作台、菜品分配和独立打包。产品面向海外华人，默认简体中文，繁体作为后续语言选项。马卡蒂店、价格、优惠与订单号用于演示；币种和营业时间以门店设置为准。

三种模板是同一页面的不同布局，功能和验收规则共用。效果图已出现入口但尚未展示完整流程的页面标为「补齐」。方案中的建议默认规则可在产品评审时调整。

## 使用角色

| 人员 | 主要职责 |
|---|---|
| 顾客 | 外卖／自取、扫码或 iPad 堂食，只查看自己的外卖订单或当前桌次 |
| 店长／管理员 | 配置本店菜单、模板、活动、工作台与员工权限 |
| 店员／接单员 | 开台、开单、接拒单、加菜、按权限处理账单和指派骑手 |
| 后厨／打包／出餐 | 按工作台制作，按整单打包，确认送桌或交接 |
| 自营骑手 | 处理指派给自己的配送任务，确认实际取餐、送达与代收 |

## 跨页面业务规则

| 规则 | 在多个页面的同一行为 |
|---|---|
| 订单与任务 | 接单或送厨后，菜品按本门店的设置分派至各制作台，保留原单号；套餐按实际子项分派。各台逐项报备好，全齐才进入待打包或堂食待出餐。 |
| 状态独立 | 制作任务分待制作、制作中、已备好；打包分待齐菜、待打包、已打包；出餐交付分待送桌／待取餐、已上桌／已交接及后续配送。付款及退款单独显示。 |
| 堂食桌次 | 门店开台后，扫码和 iPad 共享当前桌次及已提交账单。新加菜以独立批次送厨；柜台结账关台后，换客不显示旧账单。 |
| 金额与活动 | 币种按门店，分列菜品、包装、配送与优惠。示例满减按参与菜品小计计算。提交时核对，已确认订单保留当时价格和优惠。 |
| 打包与交接 | 打包员核对菜品、规格、顾客备注及餐袋数，可在骑手到店前装袋。交接后自营单才进入配送中。自取是否进打包由门店设置，普通堂食直接送桌。 |
| 平台订单 | GrabFood、foodpanda 以实际开通门店和能力为准。只同步已接订单时，不在本系统开放平台未授权的操作。内部备好、打包、交接与外部平台确认状态分开显示。 |
| 重复与异常 | 重复提交、恢复连接或平台重送先核对原结果，不重复接单、制作、装袋、取餐或收款。拒单、取消、改派、撤回应留原因，通知受影响岗位。 |

## 跨页验收情景

1. 顾客更换收餐地址后配送费更新，结账先展示新金额，再由顾客确认。店员只收到一单。
2. 08 桌分别用扫码与 iPad 点菜，后厨收到两批，柜台按同桌次结账；换客后新顾客看不到旧账单。
3. 一单同时含炸物和饮品，各台只看自己的项目。打包台在饮品未好时显示缺项，直到齐菜并核对才能完成。
4. 未分台菜品仍在总览提示，补分或处理后才参与齐菜判定。
5. WEB-108 提前打包 1 袋，实际交接后进入配送中，送达前不会显示已送达。
6. 骑手现场实收 ₱248 并确认送达，门店对代收现金另行核款。重复操作不多记现金。
7. 导入 2 行通过、1 行缺分类，确认只生成 2 个草稿；顾客菜单在发布后变化。
8. 晚餐满减未达门槛和已达门槛的两种账单金额正确；暂停活动只影响后续提交单。
9. 重复同步平台订单不重复出单；取消正在制作的外卖单时，受影响工位与打包台都能看到提示。
