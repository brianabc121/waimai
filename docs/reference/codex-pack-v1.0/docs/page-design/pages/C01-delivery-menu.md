# C01 外卖店铺点菜

**依据**　效果图

**使用角色与入口**　顾客；商家分享链接、已访问门店入口

**目标**　让顾客先找到菜，再明确配送或自取条件。

**界面内容**　店名和门店、外送／自取、地址与预计时间、点菜／门店标签、左侧分类、商品列表、活动提示、固定购物车。

**主要操作**　进入链接默认使用门店可用的服务方式；浏览分类或搜索；普通菜点击加号，有必选规格或套餐构成的菜先打开选择页；底栏显示所选数量与菜品小计。三套模板分别呈现左栏列表、招牌推荐、双列商品，沿用相同菜单和操作。

**规则与异常**　空地址可浏览与选菜，确认地址后才显示实际配送费和预计时段。模式切换保留两渠道都可售的菜并说明改价或不可售项；移除前明确提示。非营业或暂停接单时可浏览；未启用的服务方式不显示在切换项。

**验收条件**

- 新顾客无地址也能看到菜单；确认地址前不把估算配送费写成最终费用。
- 同一门店切换模板后，菜单项、活动条件及已选购物车含义一致。
