# C02 门店信息

**依据**　从「门店」入口补齐

**使用角色与入口**　顾客；外卖点菜页或堂食点菜页的门店入口

**目标**　在离开点菜列表前，确认店家、营业时间和交付方式。

**界面内容**　门店名称、营业状态、营业时段、门店地址；根据渠道展示外送说明、自取位置或门店联系方式。

**主要操作**　用户打开门店信息，查看今日营业、自取说明或外送是否开放；从已公开的联系入口联系门店；返回原点菜页和分类位置。

**规则与异常**　营业时间以门店当地时间显示。门店停业与外卖暂停是不同状态，按渠道标注。没有填写的门店信息不显示空白按钮。该页只展示商家公开信息。

**验收条件**

- 外卖暂停时仍可查看营业时间，能看清是否还有自取。
- 返回菜单时不清空已选菜品。
