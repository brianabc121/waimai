# C04 菜品规格选择

**依据**　效果图

**使用角色与入口**　顾客或店员；各点菜界面的「选规格」或购物车编辑

**目标**　明确选好规格与口味后再入单，后厨能看到相同要求。

**界面内容**　菜名、图片、基础价、规格／口味／加料、数量、备注、随选项变化的合计、加入购物车。

**主要操作**　选择所有必选项，例如「中辣」，调整数量，查看规格加价后的金额，再加入或保存到购物车。不同口味或备注拆成独立行；编辑时带回已有选择。

**规则与异常**　必选未完成、选项售罄或超过限选数量时不能加入；显示具体原因。自由备注不能替代必选规格。切换点餐渠道后，旧规格失效时要求重新选择。

**验收条件**

- 同一份菜的微辣和中辣分别保留，后厨看得到各自数量。
- 从购物车保存规格修改只变更该行，不额外新增一份。
