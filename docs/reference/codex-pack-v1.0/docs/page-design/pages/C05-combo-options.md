# C05 套餐选择

**依据**　从「选套餐」入口补齐

**使用角色与入口**　顾客或店员；菜单套餐行的「选套餐」

**目标**　让组合餐的必选项、加价和后厨拆分容易核对。

**界面内容**　套餐名、基础价、套餐组和各组的必选份数、当前选项、加价、数量与加入按钮。

**主要操作**　按每个组选主食、小吃或饮品；各组选够后确认套餐与金额。购物车展示套餐为一行并可展开配餐，后厨按照套餐内实际菜品分派，打包仍按同一整单核对。

**规则与异常**　缺货的套餐子项不能选；可换项时按允许的组合及加价展示；无可用必选项时该套餐不可下单。同一套餐的内容或口味不同应分行，避免送错。

**验收条件**

- 必选「两款炸物」只选一款时，给出缺一项的提示。
- 套餐中的炸物进炸台、饮品进饮品台，打包能看到组合关系。
