# C06 外卖购物车

**依据**　效果图

**使用角色与入口**　外送或自取顾客；点菜页底栏

**目标**　在结账前核对菜品、数量和选项。

**界面内容**　当前门店和服务方式、所选菜品和套餐、规格备注、数量调整、菜品小计、优惠进度与去结算。

**主要操作**　顾客可调整数量、编辑规格、删除菜品或确认清空；回菜单继续选菜；点击去结算，把当前购物内容带入对应服务方式。

**规则与异常**　购物车按门店核对，切换门店时先说明可保留或需重选的内容。菜品小计与应付总额明确区分；售罄、价格变化或优惠变化提示确认。空购物车返回菜单。

**验收条件**

- 增加或减少一份后，小计和满减差额同步更新。
- 清空需要明确操作，完成后不会进入空单结账。
