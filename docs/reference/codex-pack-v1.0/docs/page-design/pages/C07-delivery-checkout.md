# C07 外卖／自取确认订单与结账

**依据**　效果图（优惠未达标与已抵扣两态）

**使用角色与入口**　顾客；外卖购物车的「去结算」

**目标**　让顾客在提交前看清交付方式、活动和应付金额。

**界面内容**　外送地址或自取门店、预计时间、菜品及备注、包装费、配送费、活动优惠、应付与付款方式。

**主要操作**　核对资料，选择门店已开启的付款方式，查看优惠资格后提交。地址、菜单或活动在提交前发生变化时，展示重新计算的账单并要求确认。提交成功后进入订单进度。

**规则与异常**　外送必需有效地址；自取显示取餐门店和方式，未产生配送费时不计配送费。示例活动按参与菜品小计满 ₱499 减 ₱50，低于门槛显示差额；包装费与配送费单列。提交中保护按钮，超时先查结果，避免重复订单。仅在确认支付结果后显示已付款。

**验收条件**

- 菜品小计 ₱460、配送费 ₱69 时，提示还差 ₱39，应付 ₱529。
- 菜品小计 ₱520、减 ₱50、配送费 ₱69 时应付 ₱539，优惠单列。
