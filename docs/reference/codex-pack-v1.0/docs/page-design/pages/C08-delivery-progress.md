# C08 外卖／自取订单进度

**依据**　从结账和骑手效果图补齐

**使用角色与入口**　顾客；下单回执、订单链接或自取凭证

**目标**　让顾客知道商家有没有接单、什么时候可取或送到。

**界面内容**　订单号、门店、当前进度、预计时间、订单摘要、付款状态、联系门店。自取显示可核对的取餐号。

**主要操作**　提交后先显示「待接单」，商家确认后进入备餐。外送根据实际进入「待骑手取餐／配送中／已送达」；自取在门店确认备妥后显示「可以取餐」，交餐后显示「已取餐」。仅在权限及订单状态允许时提供取消或联系入口。

**规则与异常**　厨房齐菜、已打包、交给骑手是不同事件；顾客端不提前展示「配送中」。拒单、取消或配送失败说明当前结果，已付款订单单独显示退款进度。重新打开凭证可查看原单，凭证不暴露其他顾客订单。

**验收条件**

- 打包完成但尚未交给骑手时，状态仍是待骑手取餐。
- 货到付款单送达前仍显示待付款，关闭页面后能凭原订单入口找回来。
