# C09 扫码堂食点菜

**依据**　效果图（左栏快选、招牌推荐、双列）

**使用角色与入口**　顾客；扫描门店桌码

**目标**　让顾客确认桌位后快速点菜，与同桌加菜、结账关联。

**界面内容**　门店、醒目桌号、点菜／已点菜、呼叫店员、分类与菜品、底部已选数量和金额。

**主要操作**　扫桌码识别门店和桌位；桌台已开时进入当前用餐批次，选菜后一键进入确认点菜。用餐中可查看本桌订单或呼叫店员。三套模板保留相同桌位、购物车和确认入口。

**规则与异常**　首版建议服务员开台。未开台或已结账时允许浏览并提示联系店员，不能给旧桌次下单。呼叫店员需要有效桌次，重复触发先显示已发送。扫码堂食使用堂食价和可售规则。

**验收条件**

- 08 桌扫错码时能在确认前看见桌号，无需输入送餐地址。
- 结账后换客，新顾客看不到上一桌次账单。
