# C10 堂食确认点菜

**依据**　效果图

**使用角色与入口**　手机扫码或 iPad 顾客；「查看已选」

**目标**　在发送前确认桌号、口味和本次菜品金额。

**界面内容**　桌号、本次菜品和规格、数量编辑、本次小计、结账方式提示、提交点菜。

**主要操作**　顾客核对当前桌和本批菜品；可返回编辑；确认店员接单模式后提交，转到成功或异常状态。加菜时显示本次新增小计，既有菜品从已点清单查看。

**规则与异常**　示例为到柜台付款。已发送菜品不混入下一批；如果桌次在提交前关闭，禁止提交并提示找店员；重连或重复点击先查询本批结果。

**验收条件**

- 确认页显示正确桌号及「中辣」等规格，且无配送费。
- 连续点击提交只生成一次用餐批次。
