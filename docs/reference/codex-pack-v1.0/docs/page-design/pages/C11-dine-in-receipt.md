# C11 堂食点菜提交结果

**依据**　效果图

**使用角色与入口**　顾客；提交堂食点菜后

**目标**　把「系统已收到」和「门店已接单」说清楚。

**界面内容**　提交结果、单号或批次、桌号、当前状态、柜台付款提示、查看已点或继续加菜。

**主要操作**　成功时显示单号和「待商家确认」或门店实际状态；可以继续加菜，也能到已点菜查进度。失败或超时时显示对应原因和恢复入口，只有确认失败后才允许重试。

**规则与异常**　提交成功不等于已付款或制作完成。返回原页面时不再自动提交。门店拒单时可引导顾客查看原因与当前账单。

**验收条件**

- 等待商家确认时不提示已出餐；后续状态更新能在已点菜中查看。
- 成功回执可辨认同一笔订单，刷新不重复点菜。
