# C12 本桌已点菜与继续加菜

**依据**　效果图

**使用角色与入口**　顾客；堂食「已点菜」或成功页

**目标**　让同桌持续核对上菜和结账，支持分批点菜。

**界面内容**　本桌号码、点菜批次、菜名和规格、制作与上菜状态、本桌小计、继续加菜。

**主要操作**　按批次看菜品状态；继续加菜返回菜单，另建本批购物车，再次确认后只把新批次送厨；同一桌次将有效批次汇总到一张账单。

**规则与异常**　已取消／退款的项以实际结算规则展示，保持变更记录。顾客只浏览有效桌次；柜台确认结账后关闭加菜动作。堂食部分上菜时可分项显示，不能把整个桌次直接标为完成。

**验收条件**

- 08 桌第二次加菜，已点菜能区分两批；后厨只新增本次菜品。
- 已送桌的菜仍能在本桌账单查到，结账后不能再加菜。
