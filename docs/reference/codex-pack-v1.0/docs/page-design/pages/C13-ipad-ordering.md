# C13 iPad 桌面自助点菜

**依据**　效果图（三栏快选、招牌大图、商品卡片）

**使用角色与入口**　顾客；由门店预绑定桌位的 iPad；管理者负责配对

**目标**　利用横屏空间服务同桌多人，无需客人扫码。

**界面内容**　桌号、呼叫店员、菜单分类、菜品与口味选择、数量、已选订单区及确认操作。

**主要操作**　设备以门店设置的桌号进入当前桌次。三栏快选同屏显示分类、菜品和购物车；招牌大图强调图与口味选择；商品卡片以网格呈现。确认、提交、加菜和柜台结账沿用堂食路径。

**规则与异常**　换桌或重新绑定由店员操作。结账或换客后清掉上一桌次的可见内容；设备重新联网先核对当前桌次。iPad 和扫码共享堂食菜单、价格及已提交的本桌账单，未提交购物内容不承诺跨设备同步。

**验收条件**

- 绑定 08 桌的 iPad 下单显示堂食 08 桌，后厨与扫码入口按同样规则分工。
- 三种布局的必选规格、加菜和确认行为一致，换客后旧内容不展示。
