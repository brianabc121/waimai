# K01 后厨总览

**依据**　效果图；以新增工作台及打包规则更新

**使用角色与入口**　厨师长、后厨人员、出餐员；后厨「总览」

**目标**　从整单视角看待做、制作中、齐菜、出餐／待打包和异常任务。

**界面内容**　门店、固定总览及打包入口、当前启用的自定义工作台导航、订单卡、来源与桌号、等待时长、各工位进度、未分配提醒。

**主要操作**　接单或店员送厨后，按订单聚合来自各台的生产任务；可切换工作台或打开订单详情。单人门店可在有权限时从总览处理中间步骤。堂食备好进入出餐；需打包的订单齐菜后进入待打包。

**规则与异常**　总览显示原单号和加菜批次。同一菜品取消、超时或工位未分配时给出文字提示。未分配但需要制作的菜可以由负责人补分或在总览处理；处理前不用于整单齐菜。超时按本门店可配置的制作目标计算。

**验收条件**

- 菜品分发到两个工作台后，总览仍显示同一笔订单和两项进度。
- 断开连接时明确标识显示内容可能过期；恢复后核对新增和变更，不重复显示任务。
