# K02 自定义制作工作台

**依据**　最新效果图（炸台为一例）

**使用角色与入口**　制作人员；后厨导航选择被分配的工作台

**目标**　确保各台只看到自己要做的实际菜品，能逐项反馈。

**界面内容**　自定义台名、待做／制作中及已完成筛选、待做数量汇总、按订单归组的制作项、规格与备注、开始制作／标记备好。

**主要操作**　选定工作台；店员按单号和时长查菜品，开始制作，按项核对数量及规格后标记备好。单品备好更新总览和对应打包单；发现误点时在权限和交付状态允许的情况下撤回到待处理。

**规则与异常**　同一订单可以跨台，但任何工位看不到未归本台的制作项。汇总仅计未备好的实际份数；不同口味保留各自出品要求。菜品更改、取消、改派需明确显示受影响项，并避免重复制作。

**验收条件**

- 炸台看得到一份微辣和一份中辣，饮品台只收到冰柠檬茶。
- 一项备好后从炸台未完成数量扣除，未完成的饮品仍阻止外卖单显示齐菜。
