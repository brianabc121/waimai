# K03 独立外卖打包工作台

**依据**　最新效果图

**使用角色与入口**　打包员、获授权的后厨员工；后厨「打包」

**目标**　在骑手到店前核对整单、装袋并登记餐袋数。

**界面内容**　待齐菜、待打包、已打包，订单来源与预计取餐时间、缺项描述、装袋核对清单、顾客备注、餐袋数、确认打包完成。

**主要操作**　外卖接单后可预先看到全单和缺项；菜品齐后进入待打包。打包员按预计取餐时间选择订单，逐项勾选规格、数量和套餐子项，核对是否需要餐具，录入餐袋数并确认。

**规则与异常**　应制作项全部备好且装袋核对完成才可标记「已打包」。已打包表示待交付，和骑手已取餐分开。菜品临时撤回、改单时，打包员收到提醒并重新核对受影响的单。自取订单是否走此台由门店配置；普通堂食不进入。

**验收条件**

- GF-4821 缺冰柠檬茶时只显示「待齐菜」，不能完成打包。
- WEB-108 齐菜后可先装成 1 袋；骑手尚未到店时仍为待取餐。
