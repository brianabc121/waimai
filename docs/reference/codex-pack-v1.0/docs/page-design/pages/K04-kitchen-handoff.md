# K04 堂食出餐与外卖交接

**依据**　历史出餐交接效果图；按最新打包规则调整

**使用角色与入口**　出餐员、服务员、外卖取餐台人员；后厨总览或交接入口

**目标**　按交付方式确认菜是否上桌或餐袋是否交给正确人员。

**界面内容**　堂食待送、外卖／自取待交接、桌号或取餐号、订单来源、应交餐袋数、确认送桌／确认交接、已完成。

**主要操作**　堂食查看桌号和已备好的菜，送桌后确认，可按项分批上菜。外卖选择已打包单，核对取餐号和袋数后确认交骑手。自取按顾客取餐号核对后交付。

**规则与异常**　等待出品和待交接分组；已备好不等于已上桌，已打包不等于已交接。需要打包的单未完成核对时不给确认交接。骑手端确认取餐与门店交接作为同一交付环节的两侧记录，重复确认不会重复推进。

**验收条件**

- 08 桌一菜先上，可以单独确认送桌，不影响未出菜。
- FP-724 打包后等待骑手，核对袋数交接后不再出现在待交接队列。
