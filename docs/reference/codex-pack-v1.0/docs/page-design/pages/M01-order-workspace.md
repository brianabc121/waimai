# M01 多渠道订单工作台

**依据**　效果图

**使用角色与入口**　店长、收银员、接单员；商家后台「订单」

**目标**　集中处理本店不同来源的订单，先看到待接、待交付和异常。

**界面内容**　门店、渠道／状态／日期筛选、搜索、订单号、来源或桌号、下单时间、应付、制作与交付状态、订单详情入口。

**主要操作**　默认看本店待处理及进行中订单；按堂食、自营外卖、自取、GrabFood、foodpanda 搜索或过滤。选中订单打开详情执行接单等操作；渠道断开时显示最后可确认状态和平台原有处理入口提示。

**规则与异常**　按来源、外部门店与平台订单号识别重复外单。第三方只展示该门店已开通的渠道和动作；以外部已接单同步为试点建议。不同状态列分别展示，不用单个标签覆盖付款和交付。

**验收条件**

- 同一平台重送一单，列表和后厨都只有一笔有效单。
- 另一家门店及未开通渠道的订单不会出现在员工当前门店操作范围内。
