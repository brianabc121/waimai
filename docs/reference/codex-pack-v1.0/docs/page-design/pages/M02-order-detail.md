# M02 订单详情、接单与履约处理

**依据**　效果图（订单工作台详情区）

**使用角色与入口**　店长、接单员、收银员或配送管理人员；选中订单

**目标**　核对订单并明确当前由谁处理，避免误送厨、误收款或误交接。

**界面内容**　来源与单号、桌号或服务方式、菜品规格、金额分项、付款、制作、打包、交付进度、操作记录和可用动作。

**主要操作**　新单可接单或拒单，并记录原因；接单后进入制作队列。自营外送在商家安排骑手后，显示指派、取餐、送达和收款情况。堂食账单可在核对后收款关台；自取以取餐号核对交付。取消、改派及退款入口按角色和实际状态开放。

**规则与异常**　后厨已送出后发生取消，必须提醒制作与打包岗位核对；已付款的取消单保留退款进度。外部平台未开放写操作时只展示状态和处理提示。货到付款的成功送达与门店收到骑手交回的现金分别确认。

**验收条件**

- 待接单 WEB-108 仅一次接单结果进入后厨；拒单有原因且无制作任务。
- 能分别看出「已打包」「已交骑手」「已收顾客现金」「门店已核款」，不会混为一项。
