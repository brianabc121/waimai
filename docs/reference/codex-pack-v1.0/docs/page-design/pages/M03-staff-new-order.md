# M03 店员手工开单

**依据**　效果图

**使用角色与入口**　服务员、柜台人员；订单后台「新建订单」

**目标**　让店员代到店或来电顾客点菜，并送给正确门店的后厨。

**界面内容**　堂食／自取／外送、桌号或相应交付资料、分类和菜单、菜品规格、购物车、备注、金额、送后厨。

**主要操作**　选服务方式；堂食选有效桌次，未开台先按门店流程开台；自取或外送填写相应的必要交付资料。选菜、编辑口味和数量，核对金额后送厨。

**规则与异常**　使用对应渠道的价格与可售设置。外送必须核对可送范围和相关费用。送厨前允许改单；送厨后改为按批次加菜或走有记录的变更。只有店员确认实际收款才改变付款状态。

**验收条件**

- 06 桌盐酥鸡和冰柠檬茶合计 ₱238，分别派给配置好的工作台。
- 外送手工单缺有效地址时，明确提示缺项，已选菜品仍保留。
