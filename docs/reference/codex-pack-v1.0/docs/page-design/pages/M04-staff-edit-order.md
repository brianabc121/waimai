# M04 修改订单与已送厨加菜

**依据**　效果图

**使用角色与入口**　店员、店长；订单详情「编辑订单／加菜」

**目标**　允许调整未发出的内容，同时防止已制作菜品被无声改掉或重复派发。

**界面内容**　原单状态、已送厨菜品、本次修改或新增菜品、规格及数量、加菜小计、更新后应付、送厨动作。

**主要操作**　尚未送厨的菜可改数量、规格、备注和删除。已送厨的菜按原批次显示；新增菜先审核再单独发送。需撤掉或变更已送厨菜品时按门店权限填写原因、提交变更，相关工作台与打包台收到明确提醒。

**规则与异常**　新增用原单号下的新批次，不重发历史菜品。优惠与已收款的处理应在提交改动前显示差额；已付款退减走受控处理。整单已打包时，如允许改单，先退回待核对；交付后走订单售后处理。

**验收条件**

- 示例原单 ₱238，加一份无盐地瓜条 ₱99 后合计 ₱337，厨房只看到新增菜。
- 退掉制作中的菜，厨房能看到取消该项的提示，而非从屏幕无声消失。
