# M05 菜单管理与可售状态

**依据**　效果图

**使用角色与入口**　店长或菜单管理员；商家后台「菜单」

**目标**　维护一套菜单，按渠道管理不同售价、可售状态和工位归属。

**界面内容**　分类、搜索、菜品名称及缩略图、价格、渠道、发布和可售状态、制作工作台、导入／新增。

**主要操作**　通过分类或名称定位菜品，进入单品编辑。可快速标记临时售罄或恢复，按菜品归属页面批量分配工位；通过导入扩充菜单。

**规则与异常**　草稿仅后台可见，发布后按有效渠道展示；临时售罄与永久下架分别管理。堂食扫码和 iPad 使用同一堂食规则，且菜单改价不追溯已提交订单。平台菜单是否独立同步取决于实际合作范围。

**验收条件**

- 标售罄后新顾客不能下单该菜，但后厨已有单仍可见。
- 只改自营外卖价时，堂食扫码和 iPad 价格不受影响。
