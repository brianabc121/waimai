# M06 菜单 Excel 上传与导入预览

**依据**　效果图

**使用角色与入口**　菜单管理员；菜单管理「批量导入」

**目标**　批量录入菜单，给商家预览和纠错机会。

**界面内容**　下载模板、上传、导入预览、通过与错误统计、行级问题、确认导入为草稿。

**主要操作**　下载模板并上传填好的表格。先预览每行菜名、分类、基础价和分配信息；系统标出缺项、格式错误或疑似重复行。商家可修正再上传，或确认仅将通过的行导入草稿。

**规则与异常**　重复导入可能更新现有菜时，必须展示是新增还是更新并由管理员确认；无法判定的行不可覆盖。未经发布不影响顾客端。预览与导入结果要能对应，失败行保留原因。

**验收条件**

- 预览中 2 行通过、1 行缺分类，只确认 2 行后，菜单出现 2 个草稿。
- 同一表格再次上传时会识别疑似重复，不能默默产生重复商品。
