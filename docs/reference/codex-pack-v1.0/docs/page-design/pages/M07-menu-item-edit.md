# M07 新增／编辑菜品与规格

**依据**　效果图

**使用角色与入口**　菜单管理员；菜单列表的新增或编辑

**目标**　集中设置菜名、照片、销售规则和制作工作台。

**界面内容**　菜名、图片、分类、描述、堂食与外卖价格、渠道可售、规格组和加价、制作工作台、保存草稿／发布。

**主要操作**　填写基本信息与价格，配置辣度等选项的必选和可选数量；在工作台选择已启用的制作台；保存草稿或审核发布。套餐在这里维护配餐组和子项。

**规则与异常**　不同渠道可设各自价格；可售渠道应有有效价格。保留发布前预览。已明确不需制作的商品可标为免制作；需要制作但暂未分台的项进入总览的未分配提醒。编辑或下架不改已下单的菜名、金额和历史规格。

**验收条件**

- 发布后中辣选项进入顾客页，后厨在本项看到正确口味。
- 只保存草稿时对顾客仍展示上一已发布版本。
