# M08 店铺模板选择、预览与发布

**依据**　效果图

**使用角色与入口**　店长或有装修权限的员工；后台「店铺装修」

**目标**　让商家给三种点餐入口设置适配的样式。

**界面内容**　外卖、扫码堂食、iPad 堂食三个频道，模板列表、当前使用与待发布标记、设备预览、店标封面主题色、发布。

**主要操作**　进入频道，挑选对应模板，预览本门店已发布菜单；按需调整店标、主题色和封面，确认发布。扫码可对照模拟桌号，iPad 提供横屏预览。

**规则与异常**　三个频道独立保存和发布，模板更换只改变界面布局，不修改菜单、订单、桌码或分享链接。临时保存继续显示当前线上模板；未结账顾客仍能使用当前购物流程。

**验收条件**

- 只发布外卖模板，扫码与 iPad 原模板不变。
- 左栏、招牌、双列三套预览得到同一门店的菜品及价格。
