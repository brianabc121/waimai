# M09 活动列表

**依据**　效果图

**使用角色与入口**　店长或活动管理员；后台「活动」

**目标**　查到每个活动何时、在哪个渠道生效，以及能做的操作。

**界面内容**　门店与渠道筛选、活动名称、优惠类型、时段、草稿／待开始／进行中／已暂停／已结束状态、新建、查看和编辑。

**主要操作**　按门店、渠道或状态筛选，从新建进入设置，已有活动进入详情。草稿、预定活动、进行中活动分别显示可用操作。

**规则与异常**　活动的生效日期和每日时段使用门店当地时间；处于生效日期但不在每日时段时，标明「今日待开始」或当前不生效，避免误解。未发布的草稿不进入顾客结算。

**验收条件**

- 自营外卖、堂食、自取各活动可按渠道筛出。
- 暂停的活动和自然到期的活动显示不同状态。
