# M10 活动创建与编辑

**依据**　效果图

**使用角色与入口**　活动管理员；活动列表新建或详情编辑

**目标**　配置规则、渠道、时段，发布前核对顾客实付。

**界面内容**　活动名、满减／折扣／免配送费、参与范围、门槛及金额、适用渠道、起止日期和每日时段、订单预览、草稿／发布。

**主要操作**　选择活动类型，设置有效规则及时间；用样例购物车看未达门槛、已达门槛两态。保存草稿或发布。活动与其他优惠冲突的处理规则需在发布前显示。

**规则与异常**　首版建议同一订单只自动应用一个最优惠的可用活动，组合规则另行评审。免配送费只适用于有配送费的服务。活动修改或暂停针对后续提交的订单；已确认的历史优惠继续可查。平台活动不与商家自营活动默认共用。

**验收条件**

- 晚餐满 ₱499 减 ₱50 仅在设定的自营外卖日期和时段有效。
- 满减金额、折扣率或起止时间不合法时，标出问题并阻止发布。
