# M11 活动详情、用量与暂停

**依据**　效果图

**使用角色与入口**　活动管理员；活动列表的「查看」

**目标**　核对已生效规则和使用情况，并安全暂停活动。

**界面内容**　规则、适用渠道、活动状态、使用订单数、累计优惠、最近使用订单、编辑、暂停／恢复。

**主要操作**　查看活动状态和订单，订单入口跳到详情；暂停前说明生效时间和影响对象；恢复时重新判断日期及渠道是否有效，显示最终状态。

**规则与异常**　建议统计以有效确认订单为主，取消或全额退款的订单从有效用量中扣除，标注统计口径。活动暂停不重算已确认订单；进行中的顾客在提交前重新核对优惠。

**验收条件**

- 24 笔有效订单每笔减 ₱50 时，累计优惠显示 ₱1,200。
- 暂停后新提交单不享受该活动，既有订单仍能查看当时优惠。
