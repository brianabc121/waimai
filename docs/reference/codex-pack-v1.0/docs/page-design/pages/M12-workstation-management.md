# M12 后厨自定义工作台管理

**依据**　最新效果图

**使用角色与入口**　店长或后厨管理员；商家后台「后厨设置」

**目标**　按门店实际分工设置制作台，让厨房导航自动呈现启用的工作台。

**界面内容**　工作台列表、名称、启用状态、排序、关联菜品与未完成任务提示、新建和编辑。

**主要操作**　新建炸台、饮品台或热厨台等；保存后出现在后厨与菜单工作台选项里。可改名和调顺序；停用前查看归属菜及未完任务，并确认如何继续处理。

**规则与异常**　工作台属本门店，启用时名称不可重复。总览和打包是独立固定入口。停用后的工作台不接新任务，旧任务仍能完成或由有权限的人员明确改派；不能让任务消失。

**验收条件**

- 保存热厨台后，菜单选择器和后厨导航都能找到热厨台。
- 停用仍有未完成制作任务的炸台，会要求明确处理方式。
