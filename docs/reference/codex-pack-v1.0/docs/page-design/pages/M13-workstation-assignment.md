# M13 菜品工作台归属与批量分配

**依据**　最新效果图（菜单内工作台下拉及批量分配入口）

**使用角色与入口**　菜单管理员或后厨管理员；菜单列表或菜品编辑

**目标**　让菜单在发单前有明确的制作分工，同时保留未分配兜底。

**界面内容**　菜品与分类、当前制作工作台、未分配／免制作标记、已启用工作台下拉、批量分配、结果与错误。

**主要操作**　可逐道菜选择工作台，也可筛出同类菜后批量调整。套餐按子项各自工作台发送。发布分工调整前展示受影响菜品。

**规则与异常**　建议首版每个制作项归一个工作台；跨台按套餐子项拆分。同一订单按已确认的工作台分派，后续配置只影响新派发菜品；在制改单由后厨明确改派。未分配但需要出品的项在总览提示，不能被当成已备好。

**验收条件**

- 盐酥鸡与地瓜条分给炸台、冰柠檬茶分给饮品台，同一单的三个项正确落到两台。
- 批量分配遇到已停用工作台时能看到失败原因；不影响已经确认的任务。
