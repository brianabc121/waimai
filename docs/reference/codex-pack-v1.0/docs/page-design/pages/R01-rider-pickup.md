# R01 骑手到店取餐

**依据**　效果图

**使用角色与入口**　被指派的自营骑手；从自己的配送任务打开

**目标**　知道门店位置、备餐状态和应取餐袋数。

**界面内容**　订单号、门店与取餐台、待准备／已打包、餐袋数、导航到店、联系门店、确认取餐。

**主要操作**　骑手打开已指派订单，导航到门店；对照单号和袋数，当场确认取餐。未打包可查看等待状态；发现袋数不符、订单已取消或换人配送时联系门店处理。

**规则与异常**　骑手只访问已指派且可处理的自营订单。取餐确认以包裹已准备并实际交付为准；商家或骑手重复通知不产生第二次取餐。未确认取餐前不向顾客显示「配送中」。

**验收条件**

- 未打包的订单能看见等待状态，并禁止误确认取餐。
- 1 袋正确交接后，骑手任务推进到配送中，两个端显示同一笔 WEB-108。
