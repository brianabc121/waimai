常见问题

要买专门的收银机吗？

不用。现有的手机、平板、电脑打开浏览器就能用；员工 App 支持安卓和 iPhone。

能接 GrabFood、foodpanda 的单吗？

正在规划中，需要你的商户授权后开通。

支持哪些付款方式？

现金、银行转账和当地常用电子钱包，可以按店设置；线上支付接入规划中。

我的数据安全吗？

每家店的数据单独隔离，每天自动备份；员工按角色只能看到被授权的内容。

多少钱？

按门店和功能报价，单店和连锁都有方案，见价格页或预约演示。
